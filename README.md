# Furniture Commerce OS — ديمو تفاعلي

ديمو عربي RTL لمشروع أثاث عائلي (ورشتان تجريبيتان). يعرض كتالوجًا، طلب استفسار، لوحة تشغيل للطلبات وعروض الأسعار والدفعات التجريبية.

**هذا ديمو فقط — ليس نظام إنتاج ولا محاسبة ولا دفع حقيقي.**

- الأسعار والعملاء والطلبات وهمية.
- البيانات تُحفظ في `localStorage` للمتصفح الحالي فقط ولا تُزامَن بين أجهزة.
- لوحة التشغيل رابطها عام تقنيًا على موقع static (لا صلاحيات حقيقية).

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح `http://localhost:5173/furniture-commerce-os/` (أو حسب إعداد Vite).

```bash
npm test          # قواعد الحسابات (Vitest)
npm run build     # بناء الإنتاج
npm run preview   # معاينة البناء
```

## المسارات

| المسار | الوظيفة |
|--------|---------|
| `/` | الصفحة الرئيسية |
| `/catalog` | الكتالوج + بحث + فلاتر |
| `/product/:id` | تفاصيل منتج |
| `/inquiry` | نموذج استفسار/طلب |
| `/ops` | لوحة التشغيل (ديمو) |
| `/ops/orders` | قائمة الطلبات |
| `/ops/orders/:id` | تفاصيل طلب + عرض سعر + دفعات |
| `/ops/products` | إدارة منتجات الديمو |

## إعادة ضبط البيانات

من لوحة التشغيل → زر «إعادة ضبط البيانات» (يؤكد قبل المسح).

## النشر (GitHub Pages)

- `base` في `vite.config.ts` مضبوط على `/furniture-commerce-os/`
- Workflow في `.github/workflows/pages.yml` يبني وينشر إلى GitHub Pages
- بعد التفعيل: `https://tawffik.github.io/furniture-commerce-os/`

## القيود

- لا Backend ولا قاعدة بيانات مشتركة.
- لا مدفوعات حقيقية ولا تكامل واتساب/فيسبوك.
- لا تكلفة تصنيع ولا مخزون حقيقي.
- الافتراضات موثّقة في `docs/ASSUMPTIONS.md`.
