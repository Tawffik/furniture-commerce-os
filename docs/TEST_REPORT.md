## اختبارات وحدات (Vitest)

ملف: `src/lib/money.test.ts`

| القاعدة | النتيجة المتوقعة |
|---------|------------------|
| lineTotal يرفض السالب | 0 |
| orderTotal مع خصم ورسوم | sum − discount + fees |
| remainingBalance لا يصبح سالبًا | ≥ 0 |
| paymentStatus | غير مدفوع / جزئي / مدفوع بالكامل |

تشغيل: `npm test`

## مسار يدوي موصى به

1. افتح الكتالوج → فلتر/بحث.
2. افتح منتج → اطلب استفسار.
3. املأ النموذج → تحقق من المرجع.
4. لوحة التشغيل → الطلب ظاهر.
5. أضف عرض سعر (نسخة جديدة دون مسح القديمة).
6. سجّل دفعة → تحقق الرصيد المتبقي.
7. غيّر الحالة → أعد تحميل الصفحة (localStorage).
8. إعادة ضبط البيانات.
