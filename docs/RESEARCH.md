# بحث سريع — Furniture Commerce OS

## ما يحتاجه الورشة العائلية (من السياق)

- كتالوج عربي بسيط للعرض على الموبايل.
- استقبال استفسارات/طلبات بدون تعقيد.
- متابعة حالة الطلب وعرض السعر والدفعات.
- تمييز جاهز vs تفصيل.

## خيارات تقنية للديمو

| الخيار | ملاحظات |
|--------|---------|
| React + Vite + localStorage | سريع، static، مناسب لـ GitHub Pages |
| Next.js + DB | أثقل للديمو الأولي |
| WordPress/Woo | يحتاج استضافة وصيانة |

**الاختيار:** React + Vite + TypeScript + localStorage — أقل تكلفة وأوضح للعرض.

## حدود مقصودة

- لا Backend، لا مزامنة بين أجهزة.
- لا مدفوعات حقيقية.
- لا صور منتجات حقيقية (ألوان تجريبية).
- لوحة التشغيل ليست نظام صلاحيات إنتاجي.
